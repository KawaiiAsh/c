# AFTERBURN · 超燃飞行

机场侧面视角的实时 3D Crash Game 动画演示。点击「启动飞行」，观看战斗机滑跑、抬头离地、收起落架、持续爬升与最终爆燃。

## 打开

直接用 Chrome 或 Edge 打开本目录的 `index.html` 即可。不需要安装、不需要联网，也不需要构建。请保持 `vendor` 文件夹与其他文件的相对位置。

## 操作

- 启动飞行 / 重新起飞：开始完整的 26.5 秒演示。
- 暂停按钮或空格：暂停与继续；待机时空格启动。
- 触发 CRASH：立即触发爆燃和飞行结束。
- 右上角扬声器：开启 / 关闭合成引擎、气流与爆燃音效，默认静音。
- 影院模式：收起 HUD；Esc 退出影院模式。
- 全屏：进入 / 退出浏览器全屏。
- R：重新起飞（焦点不在按钮上时）。

## 内容与结构

- `main.js`：机场、山脉、天空与云层、飞行轨迹、镜头跟随、粒子、音效和交互。
- `jet.js`：可独立复用的程序化战斗机，包含双发动机、透明座舱、机翼、起落架和加力尾焰。
- `index.html` / `style.css`：响应式中文飞行 HUD。
- `vendor/three.min.js`：本地 Three.js 0.160.1，MIT 许可证见同目录 `THREE-LICENSE.txt`。

这是动画展示原型，倍率按时间增长、终止时刻固定，不包含投注、支付或真实输赢。可通过 `window.afterburn.start()` 与 `window.afterburn.crash()` 从现有游戏逻辑调用；`state`、`time`、`multiplier`、`paused` 可只读查询。修改 `main.js` 中的 `duration` 可调整自动结束时间。
